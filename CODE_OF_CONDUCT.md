# Code of Conduct

## Our standards

CARTOGRAPH aims to be a welcoming, technically rigorous project. Participants are expected to:

- communicate respectfully and assume good faith while discussing technical disagreements;
- focus criticism on ideas, evidence, and code rather than people;
- explain uncertainty, limitations, and security impact clearly;
- respect privacy, licenses, attribution, and the boundaries of repositories being analyzed;
- accept correction and help keep project spaces useful for contributors with different backgrounds and experience.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, doxxing, sexualized conduct, unwanted contact, deliberate disruption, publishing private information, or attempting to obtain or expose credentials or proprietary source code.

## Scope and enforcement

This policy applies in project repositories, issue trackers, discussions, pull requests, and other spaces where someone is representing CARTOGRAPH. Maintainers may remove content, close discussions, restrict participation, or take other action when behavior violates this policy or threatens the safety and privacy of participants.

Report conduct concerns privately through the maintainer’s [AlisinaDevelo GitHub profile](https://github.com/AlisinaDevelo). Do not use public issues for sensitive reports. Security vulnerabilities should follow [`SECURITY.md`](SECURITY.md).

Retaliation against a good-faith report is not acceptable. Reports will be handled as confidentially as practical, with information shared only when needed to assess or address the concern.
