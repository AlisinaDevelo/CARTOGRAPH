# CARTOGRAPH sample repository

This small NodeNext TypeScript repository is the copyable example used by the
[CARTOGRAPH quickstart](../../docs/QUICKSTART.md). It intentionally contains a
local module import and a named function so the first scan has useful evidence.

The quickstart copies this directory to a temporary Git repository, makes one
small source change, and runs both `scan` and `diff` without installing or
executing the sample's dependencies.
